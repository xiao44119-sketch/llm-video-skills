## 二、视频生产底层管线（5 步，跨 Windows/Linux 通用）

```
脚本定稿 → ①克隆音色配音 → ②ASR时间轴校准 → ③HTML分镜动画 → ④Playwright逐帧渲染 → ⑤FFmpeg编码合成
```

| 步骤 | 工具 | 说明 |
|------|------|------|
| ① 配音 | `audio_to_audio_plus` | 传入克隆音色参考 URL + 口播稿 + 发音标注，生成 WAV |
| ② ASR | `mediakit-cli video asr-subtitles` | 配音 WAV → 每条字幕精确起止时间戳，用于画面卡点和字幕对齐 |
| ③ HTML | 手写单文件 HTML | 核心协议：暴露 `window.renderFrame(t)`，传入时间 t 计算所有元素位置/透明度/缩放 |
| ④ 渲染 | Playwright + Chromium | 无头浏览器按 20fps 调 `renderFrame(t)` 截图，攒出 PNG 序列 |
| ⑤ 合成 | FFmpeg | PNG 序列 → H.264 视频，混入配音 WAV → 最终 MP4 |

**关键设计协议（所有视频通用）：**
- `window.renderFrame(t)` 函数名固定，渲染脚本调用
- 工具函数：`clamp(v,a,b)` / `out(v)`（easeOutCubic）/ `set(el,p,x,y,sc)`（统一淡入上浮缩放）
- 场景切换：`scenes` 数组 + `starts` 时间点，`.active` class 控制显隐
- 转场：金色/红色光带从左扫到右（`beamWin` 数组定义转场时间点）
- 字幕：`subs` 数组 `{s,e,t}`，按时间显示，关键词用 `<span class="k">`（金）/`<span class="rk">`（红）高亮
- 背景：星空粒子 canvas + 网格线 + 径向光晕 + 螺旋光圈（四层叠加）

## 三、跨环境移植说明

### 为什么换 Linux 也能跑

这套管线的核心是 **HTML + renderFrame 协议**，跟操作系统无关。Linux 上 `node v22`、`ffmpeg`、`mediakit-cli` 都预装，只需额外装 `playwright` + `chromium`。

### Linux 环境搭建命令（新环境复用）

```bash
# 1. 建目录
mkdir -p agi-debt-video && cd agi-debt-video
npm init -y

# 2. 装 playwright
npm install playwright

# 3. 装 chromium（用户目录，绕过系统权限）
PLAYWRIGHT_BROWSERS_PATH=/home/user/.cache/ms-playwright npx playwright install chromium

# 4. 渲染（必须带环境变量）
PLAYWRIGHT_BROWSERS_PATH=/home/user/.cache/ms-playwright node render.mjs \
  --html video.html --output final.mp4 --duration 117.3 \
  --width 1920 --height 1080 --outputFps 30 --workers 4 --captureFps 20 \
  --audio voice.wav
```

### Windows 环境（已有，无需重装）

- 渲染脚本：`C:\Users\孟令骁\Doubao\chats\2026-08-24\new-chat-2\escape-ep04\render-win-opensrc.mjs`
- 该目录有 `node_modules\playwright`，直接 `node render-win-opensrc.mjs --html xxx.html ...` 即可
- 把 Linux 的 `video.html` + `voice.wav` 拷到 Windows，用 `render-win-opensrc.mjs` 也能直接重渲染
