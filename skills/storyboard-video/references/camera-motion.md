# 摄像机运动

## 三件不同的事

看起来相似，空间感完全不同：

| | 发生了什么 |
| --- | --- |
| **物体缩小** | 物体自己变小，摄像机和空间不动 |
| **场景拉远** | 整个场景在退，摄像机不动 |
| **摄像机后移** | 观察者在退，空间关系随距离重排 |

故事板上写"拉远"时，先问清楚是哪一种。

## 真正的拉远要同时影响

- 主体比例
- 背景纹理密度
- 阴影范围
- 景深
- 元素间距
- 运动速度
- 视差

只给整个页面做 `scale(0.7)`，通常会像**缩小了一张图片**，而不是镜头拉远 —— 因为纹理密度、视差、元素间距全都等比缩了，而真实镜头后移时这些量各自按不同规律变化。

## 实现要点

摄像机应该是一个独立的 CameraRig，被所有镜头共享（见 `scene-continuity.md`），而不是每个镜头各自对自己的容器做 transform。

透视投影的最小形式 —— 除以 z：

```js
const sx = cam.cx + cam.focal * x / z;
const sy = cam.cy - cam.focal * y / z;
const scale = cam.focal / z;   // 这个 scale 驱动元素大小
```

摄像机后移 = 所有元素的 z 增加。近的元素变小得快、远的变小得慢，视差自然产生 —— 这是 `scale(0.7)` 给不了的。

注意：Canvas 2D 的变换矩阵是仿射的，能做上面的逐元素投影，但**不能把一张贴图透视变形**（矩形变不成梯形）。需要在透视面上贴图时，用竖条切片法（切 N 条，每条单独仿射，N=64 基本看不出接缝），或换 Three.js。
