# 表现层决策

**任何需要"连续结构变化"的镜头，先选表示方式；表示方式没锁定，不进入动画阶段。**

一开始就做这一步，后面能少很多反复。

## 开工前写 RENDER_STRATEGY.md

```
镜头 2-3 表现层决策

目标：
- 镜头2 静态复刻故事板
- 镜头3 在镜头2 基础上连续扩张
- 视觉风格一致，允许连续几何变化，可进入参数化调节

方案比较：
1. 整图贴图    复刻快，但无法结构连续变化
2. 四块裁图    可拼装，但容易像贴图拆块
3. 局部SVG+图片 容易风格断裂
4. 全SVG      连续性好，但质感可能偏平
5. Canvas 2D  可统一质感与形变

最终选择：镜头2 与镜头3 统一使用同一套 Canvas 2D 餐盘渲染器。
```

判断依据很简单：**这个镜头之后要不要发生连续结构变化？** 要 → 从一开始就用能形变的表示方式，别用整图贴图。

同一共享主体只做一次表现层决策和一套渲染器，后续镜头用状态参数表达差异。方案锁定后，不因位置、尺寸、裁切、摄影机或特效问题重新生成已通过素材；先判断问题属于素材本身，还是素材的使用方式。

## 元素分类

| 类型 | 例子 | 用什么 |
| --- | --- | --- |
| 背景层 | 地面、墙面、环境光、远景、雾气、投影 | Canvas 渐变 / 大图 |
| 复杂静态道具 | 器物、包装、人物、食物 | **高质量透明贴图** |
| 结构性几何、规则图形 | 分区、边界、网格、线框、图表 | **Canvas** |
| 动态特效 | 粉末颗粒、碎片、烟雾、流体、光点、大量重复元素 | **Canvas** |

贴图和摄像机驱动不冲突：Canvas 2D 的矩阵是仿射的，平移、旋转、缩放、压扁都不影响贴图。只有**真透视**（边线向灭点收敛）和**网格形变**做不了，那才需要代码几何或 Three.js。

## 三层分离（最容易翻车的一条）

结构增长、侵占、裂变、包裹类的镜头，必须分成三层：

| 层 | 负责 |
| --- | --- |
| **几何层** | 轮廓、分区边界、共享分界线、扩张边界、被侵占的边界、箭头路径 |
| **纹理层** | 表面质感、材质细节、高光阴影、标签视觉 |
| **动画层** | 边界路径插值、区域占比变化、颜色变化、箭头长度变化 |

**扩张的是几何，不是纹理像素。**

反例：某个区域的边界在生长，如果把该区域的贴图块也一起拉伸，看起来就是"裁了一块图放大"，而不是这块区域长大了。正确做法是几何层的边界在动，纹理层始终按原比例平铺或裁切填充。

另外：光源在世界空间是固定的，纹样跟着物体转。所以高光扫过要留在代码里（`createLinearGradient` 叠在贴图上），别烤进贴图 —— 烤进去物体一转高光就跟着转，立刻假掉。
